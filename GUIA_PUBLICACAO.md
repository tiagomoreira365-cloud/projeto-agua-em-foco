# Guia rápido de publicação

1. Revise o nome do projeto e a descrição no README.
2. Crie um repositório chamado `projeto-agua-em-foco`.
3. Envie somente o conteúdo desta pasta.
4. Confira se os três gráficos aparecem no README.
5. Abra o notebook no GitHub e confirme a renderização.
6. Adicione na descrição do repositório: `Análise temporal do reservatório Jaguari-Jacareí com Python, pandas e Matplotlib.`
7. Use tópicos como: `python`, `pandas`, `data-analysis`, `time-series`, `matplotlib`, `portfolio`.
8. Antes de tornar público, confirme que a fonte e os dados podem ser compartilhados.

## Sugestão de texto para o portfólio

**Projeto Água em Foco** - análise de 2.474 medições diárias do reservatório Jaguari-Jacareí. O projeto abrange diagnóstico de uma fonte `.xls` com conteúdo HTML, limpeza, validação temporal, análise de sazonalidade, comparação anual e produção de relatório executivo.
